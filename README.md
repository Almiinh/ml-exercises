# Collection of ML Notebooks

This repo is a collection of Machine Learning Notebooks.

On Machine Learning:
- **Decision Trees**: Implementation of ID3 (w/ Information Gain) and CART (w/ Gini Index)
- **Ensemble Learning**: Determination of the best hyperparameters on a Random Forest Classifier
- **Perceptron**
- **Neural Networks**: Implementation of Neural networks
- **Reinforcement Learning**

On Deep Learning:
- **Image classification w/ CNN**: Classification of cat and dogs, Classification of their breeds
- **Time series prediction w/ LSTM**: Prediction of occupancy of an office room from light, temperature, humidity and CO2 measurements using statistical learning models.
- **Summarisation w/ LLM RAG**: A comparison of Vector RAG and Graph RAG pipeline to summary scientific article w/ Langchain

On Natural Language Processing:
- **Token Classification w/ BERT**: Finetuning of BERT on Part-of-Speech Tagging
